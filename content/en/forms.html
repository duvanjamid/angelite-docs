Binding fields with ngModel

[(ngModel)]="signal" connects a field to a writable signal: what the user types updates the signal, and if you change the signal, the field updates. It works for input (text, number, checkbox) and select. For forms with validation, use the reactive forms below.

The signal has to be writable

[(ngModel)] with a computed or with a value that is not a signal throws a clear error ("needs a writable signal").

Reactive forms

FormControl, FormGroup and FormArray (@duvanjamid/angelite/forms) keep their state in signals: value, errors, valid, touched and dirty. Because value is a writable signal, it binds with [(ngModel)], and because the rest are signals, the template reacts on its own.

A validator is a function (value) => null | { key: detail }. required, minLength, maxLength, min, max, pattern, email and matches (for "repeat the password") are included. The errors of several validators are merged in errors().

What is missing

There are no async validators yet. For "does that email already exist?", validate on submit with http and set the error by hand in your own state.
