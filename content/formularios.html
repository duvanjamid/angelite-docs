Enlazar campos con ngModel

[(ngModel)]="señal" conecta un campo con una señal escribible: lo que escribe el usuario actualiza la señal, y si cambias la señal, el campo se actualiza. Sirve para input (texto, número, casilla) y select. Para formularios con validación, usa los formularios reactivos de abajo.

La señal tiene que ser escribible

[(ngModel)] con un computed o con un valor que no sea una señal lanza un error claro («needs a writable signal»).

Formularios reactivos

FormControl, FormGroup y FormArray (@duvanjamid/angelite/forms) guardan su estado en señales: value, errors, valid, touched y dirty. Como value es una señal escribible, se enlaza con [(ngModel)], y como el resto son señales, la plantilla reacciona sola.

Un validador es una función (valor) => null | { clave: detalle }. Vienen required, minLength, maxLength, min, max, pattern, email y matches (para «repite la contraseña»). Los errores de varios validadores se fusionan en errors().
